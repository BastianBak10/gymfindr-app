# GymFindr

A React Native (Expo) app for finding fitness gyms near you, and sorting/filtering them by distance, price, rating, and facilities (pool, sauna, group classes, personal training, 24/7 access).

## Demo video

[Link to demo video here]

## Screens

- **Home** — list of gyms, sorted/filtered by your chosen criteria
- **Filters & Sort** — choose sort order (distance, price, rating) and toggle which facilities matter to you
- **Gym Details** — full facility list, rating, and a "Book a tour" action for a selected gym

## Running the app

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go (iOS/Android).

- Expo / React Native
